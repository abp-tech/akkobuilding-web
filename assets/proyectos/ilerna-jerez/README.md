## Optimización

24 archivos WebP: tres variantes por fotografía. Anchos de 480, 768 y 1200 px para las verticales; 480, 960 y 1855 o 1920 px para las restantes. Proporción original conservada, sin ampliar las fuentes. Altura máxima de archivo: 1600 px.

- Originales: 3,138,922 bytes.
- Suma de las variantes de mayor tamaño: 1,548,750 bytes, un 50.7 % menos.
- Total de las 24 variantes almacenadas: 2,287,052 bytes. El navegador debe elegir una variante por fotografía mediante `srcset` y `sizes`, no descargar las tres.

Se han eliminado EXIF y XMP en las copias públicas. Cada archivo se ha validado para comprobar dimensiones, peso y lectura correcta.
